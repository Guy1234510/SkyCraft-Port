# Dependency license texts

These documents preserve original third-party licenses and copyright notices.
Include this directory with compiled releases. [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)
maps each dependency to its source and applicable license.

CommonLibSSE-NG's current license is `CommonLibSSE-NG-GPL-3.0.txt`, with the
additional permissions in `CommonLibSSE-NG-EXCEPTIONS.md`. Its historical MIT
notice preserves attribution and does not replace the GPL. See
[DISTRIBUTION.md](../DISTRIBUTION.md) for corresponding-source requirements.

OpenVR headers use BSD-3-Clause; hde64 uses BSD-2-Clause. Gradle Wrapper files
use Apache-2.0. JNA is dual-licensed; this project chooses Apache-2.0.
JSpecify uses Apache-2.0. Native and Java dependency notices retain the original
authors' public attribution; they are not personal data belonging to the port's
maintainer. Keep notices embedded in any permitted dependency archives too.
