# SkyCraft — Minecraft 1.21.1 / NeoForge

Current compiled build: **1.21.1-89**, paired with Native112.

Use Minecraft 1.21.1, NeoForge 21.1.252 and Java 21. Obtain Forgified Fabric API
for NeoForge externally; this checkout uses `0.116.15+2.3.5+1.21.1`.
Install the production JAR from `Minecraft/neoforge/` in the release ZIP into
your instance's `mods` folder. Keep one active SkyCraft JAR.

Open the instance folder through your launcher rather than copying another
computer's absolute paths. Install the matching Skyrim native plugin as well:
protocol **17**, with SKSE64 and Address Library for your exact Skyrim runtime.

- [Installation in English](../docs/installation/INSTALL-EN.md)
- [Build from source](../docs/BUILDING.md)

Use a separate world from the 1.20.1 port. Compilation and Mixin verification
do not establish complete modpack or gameplay compatibility.
